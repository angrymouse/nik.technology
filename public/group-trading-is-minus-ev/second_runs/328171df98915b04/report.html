Limits and reproducibility

All these dates have been examined. None of the rows establishes a profitable independent result. A different rule was trained before each replay day; the reported return is for that selection procedure. A separate later window tested the latest fixed rule and produced zero qualifying trades. A fill must have an observed trade within ten seconds. Missing exit liquidity is written down to zero; missing entry liquidity skips entry. This is a conservative valuation rule, not a claim that a token became worthless. Drawdown uses second high/low bounds. Costs apply once to sale proceeds, excluding actual AMM price impact, transaction fees and MEV. No leverage or real trades.
